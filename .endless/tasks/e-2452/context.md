The v0.6.1 release (https://github.com/mikeschinkel/go-dt/releases/tag/v0.6.1) listed every 'Endless: record ledger entry' and similar auto-commit, burying the real changes; Mike, 2026-10-26: too much noise for a release description. The list comes from the 'Generate release notes' step of .github/workflows/release.yml, a git log from the previous tag to HEAD. E-2431 already limits a nested module's notes to commits touching its own directory, so dtx, appinfo and dtglob releases are unaffected; root notes exclude only the nested module directories (PATHS=(-- . ':(exclude)dtx' ':(exclude)appinfo' ':(exclude)dtglob')), so Endless's commits, which touch only .endless/, still appear. Suggested fix: add ':(exclude).endless' to root's PATHS, which drops commits touching only .endless/ but keeps any commit that also changes code, unlike filtering on the 'Endless:' subject. A workflow-only change: no module needs a new tag for it.
