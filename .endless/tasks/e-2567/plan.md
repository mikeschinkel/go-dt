Sentinels go in errors.go beside the existing ErrInvalid* ones.

Each Parse function follows go-dt's existing shape (ParseIdentifier, ParseDirPath): named results, NewErr with the type's sentinel plus a cause, goto end. Parse functions that take hooks or options take a pointer to an Args struct, where nil means the defaults: ParseInternetDomainArgs, ParseHostnameArgs, ParseEmailAddressArgs and ParseMailboxArgs. IP parsing uses net/netip and stores netip's canonical String().

Accessors that narrow a broader type return (T, bool): Hostname.IPAddress, Hostname.HostDomainName, Hostname.SingleLabelHostname, Hostname.InternetDomain, IPAddress.IPv4Address, IPAddress.IPv6Address. NewHostname and NewIPAddress are generic over a union constraint of their members, so a plain string argument does not compile; they cannot fail. Sideways conversions are Hostname.ToDNSName and DNSName.ToHostname, each returning an error.
